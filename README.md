Задание: Напишите компонент, который будет использовать плюрализацию интерполированного сообщения с датой.

Нужно написать компонент, который при
монтировании сгенерирует случайное целое число от
1 до 10, и выведет на экран это число в формате «У
вас N непрочитанных сообщений», где число
существительного прилагательного зависит от N, а
также в скобках выведет информацию о дате
последнего сообщения (сегодня) в коротком виде (дд
ммм чч:мм:сс)
